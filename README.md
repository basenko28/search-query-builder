# Поисковый запрос — паттерн «Строитель»

Запрос к поиску товаров: текст, условия по полям, диапазоны, сортировки,
выдача по страницам или всё подряд, подсветка совпадений, подсчёт по группам.

* `SearchQuery` — неизменяемый запрос (final-поля, нет сеттеров, приватный конструктор).
* `SearchQuery.Builder` — строитель, наружу отдаёт запрос только через `build()`.
* `build()` не даст собрать запрос без текста, условия и диапазона,
  а также запрос с постраничной выдачей и выгрузкой всего сразу.
* Одним строителем можно собрать несколько запросов — уже собранные не меняются.

Запуск тестов: `mvn test`
